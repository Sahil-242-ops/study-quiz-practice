# Study Quiz

A small Python quiz app built live with **GitHub Copilot** at the Microsoft Student Ambassadors session
"Build & Ship Your First AI App with Microsoft Foundry & GitHub".

## Run it
1. Install Python from python.org (tick "Add Python to PATH").
2. Download this repo (Code → Download ZIP) and unzip it.
3. Open a terminal in the folder and run: `python quiz.py`

## Try the Study Buddy prompt
Open copilot.microsoft.com and paste the prompt from `study_buddy_prompt.txt`.
Change the topic to anything you're studying.
